## 📦 包含核心组件说明

下载本仓库的文件后，请确保它们处于**同一个文件夹（同级目录）**下：
1. `扫书（通用型） v2.4.exe`：全交互可视化 Tkinter 外壳主程序。
2. `扫书排雷工作流.docx`：大模型规训圣经。决定 AI 的抓取尺度，你可以在里面自行修改需要严查的毒点定义。
3. `扫书 v2.4使用教程.docx`：保姆级图文操作指南。

## 🚀 极速上手三步走

1. **一键下载**：点击本页面右上角的绿色 `Code` 按钮 -> 选择 扫书（通用型） v2.4.exe`，将程序下载到本地。
2. **靶场装弹**：双击运行一次 `exe` 程序，软件会自动在同级目录下生成 `books`（小说放这里）和 `reports`（报告产出这里）两个文件夹。
3. **点火开扫**：把你想排雷的 `.txt` 小说丢进 `books`，在界面上填入你的 API Key，点击“验证节点”并选好模型，最后猛戳 **【一键启动显微镜扫书管线】** 即可！

* **🛡️ 异步线程守护**：联网鉴权、握手、DNS 解析全部在后台独立子线程运行，配合 `httpx` 5秒暴力网络熔断，**没开代理、网络卡死也绝对不会白屏无响应**。
