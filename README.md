# 🔬 扫书（通用型） v2.4 (节点分层联动记忆版) 

本仓库为 **扫书 v2.4 纯成品绿色免安装分发仓**。无需安装 Python 环境，无需配置任何代码，下载解压即可直接在 Windows 系统上全功率全自动跑通小说风控与排雷。

---

## 📦 包含核心组件说明

下载本仓库的文件后，请确保它们处于**同一个文件夹（同级目录）**下：
1. `扫书（通用型） v2.4.exe`：全交互可视化 Tkinter 外壳主程序。
2. `扫书排雷工作流.docx`：大模型规训圣经。决定 AI 的抓取尺度，你可以在里面自行修改需要严查的毒点定义。
3. `扫书 v2.4使用教程.docx`：保姆级图文操作指南。

---


## 🚀 极速上手三步走

1. **一键下载**：点击本页面右上角的绿色 `Code` 按钮 -> 选择 扫书（通用型） v2.4.exe`，将程序下载到本地。
2. **靶场装弹**：双击运行一次 `exe` 程序，软件会自动在同级目录下生成 `books`（小说放这里）和 `reports`（报告产出这里）两个文件夹。
3. **点火开扫**：把你想排雷的 `.txt` 小说丢进 `books`，在界面上填入你的 API Key，点击“验证节点”并选好模型，最后猛戳 **【一键启动显微镜扫书管线】** 即可！

## ⚡ 核心黑科技优势

* **🛡️ 异步线程守护**：联网鉴权、握手、DNS 解析全部在后台独立子线程运行，配合 `httpx` 5秒暴力网络熔断，**没开代理、网络卡死也绝对不会白屏无响应**。
* **🔄 SQLite 断点自愈接力**：中途没钱了、中转站断连、或者 Gemini 圣母病发作拒答？**换线/充值后重新启动，0秒秒跳过已完成分块，原位精准接力续扫**，绝不浪费一分钱 API 额度！
* **⚡ 节点分层级联记忆**：自动记住你的 Key 属于哪个平台，切换接口地址自动过滤，多账号历史从此整整齐齐。

当首次运行程序“扫书（通用型） v2.4.exe”后，你的根目录下最终会雷打不动地出现这几个文件和文件夹：

│
├── 📁 books (生肉小说的“兵工厂”)
├── 📁 reports (毒点报告的“陈列室”)
├── 📄 config.json (多账号防忘的“记忆账本”)
└── 📄 **小说.db (断点续扫的“深海锚点”，扫书过程中出现)
1. 📁 books 文件夹 —— 生肉小说的“兵工厂”
•	不管你想给哪本小说测雷，直接把小说的 .txt 生肉文本往这个文件夹里一扔，然后在软件界面上点一下“刷新列表”，它就会立刻出现在下拉菜单里。AI 所有的切片、抠字眼，都是从这个文件夹里把小说读进内存去解析的。
2. 📁 reports 文件夹 —— 毒点报告的“陈列室”
•	当整本书全部跑完、完美顺产后，AI 会把所有的“女主互动、雷点郁闷点、关键剧情摘要”融合在一起，用小说的名字命名，在这里吐出一份精美的 Markdown 详报。你在界面上点击“打开报告目录”，一键直达的就是这里。
3. 📄 config.json —— 多账号防忘的“记忆账本”
•	你用过多少个中转站、直连过多少个官方 Key，它都会在这张表里对齐编排。下次开机时，它负责在后台自动填上最后使用的API！”
4. 📄 **小说.db (SQLite 数据库) —— 断点续扫的“深海锚点”
临时文件
–	在扫书过程中，如果冲到第 11 块时没钱了、网络断了或者被 Gemini 的圣母风控拦截了，程序报错强退，只要临时文件还在。再次开机时，程序去读这个 db 文件，发现前 10 块都是完成状态，就会在 0.1 秒内全部闪过，直接从第 11 块原位完美接力！帮你省下大把的 API 冤枉钱！
–	注：当整本书 100% 顺利扫完、报告落盘后，这个文件会自动蒸发自毁，不占你一丝硬盘。


 扫书管线 v2.4 界面功能与操作保姆级指南

🟩 第一板块：API 线路多节点配置
•	接口地址(平台)：
–	怎么填：支持手动贴入或下拉选择。比如用 DeepSeek 官方就选 https://api.deepseek.com；想用 Gemini 官方就贴 https://generativelanguage.googleapis.com/v1beta/openai/。

•	所属 API Key：
–	怎么用：不用每次都去翻记事本复制粘贴！只要你曾经成功跑通一次，软件就会记住这个 Key 对应哪个平台。你切换上面的【接口地址】后，这里会自动刷新，只显示属于该平台的 Key。

•	模型选取 与 【🔄 验证节点并获取模型】按钮：
–	怎么操作：输入完 Key 后，必须先点击右侧的这个按钮。
–	连接成功后，【模型选取】下拉框就会把这个通道里所有可用的模型（如 deepseek-chat、gemini-3.5-flash）全部抓回来，你直接在里面选一个即可。

–	若是使用gemini api等国外api点击后，若你没开代理、梯子断了按钮会瞬间变成灰色 ⏳ 正在鉴权线路上…。等待按钮恢复，你可以安心去检查梯子。

🟩 第二板块：选择想扫的书
这里用来管理你想排雷的小说。
•	左侧下拉框：显示当前 books 文件夹里所有可以扫的 .txt 生肉小说。

•	【🔄 刷新列表】按钮：当你打开软件后，突然又往 books 文件夹里丢了几本新小说，不需要重启软件，直接点这个按钮，下拉框就会立刻同步刷出来。

•	【📂 打开报告目录】按钮：扫完书后，不需要去一层层翻资源管理器。点它，一键直达自动生成的 reports 文件夹，进去就能直接看大作文报告！
🟩 第三板块：大绿按钮 与 走马灯
•	【🚀 一键启动显微镜扫书管线】大绿按钮：
–	怎么用：当第一板块的模型选好了、第二板块的小说挑中了，无脑点它，全自动扫书正式开机！

–	点击后按钮会自动变灰并自锁，显示 ⏳ 显微镜全功率排雷中，最好不要关闭窗口…，若是关了，只要还有临时文件，能续扫。

•	进度条（绿色走马灯）：只要它在来回滚动，就说明后台 AI 正在疯狂读小说、抠字眼，程序活得好好的。
🟩 第四板块：扫描实时日志

•	怎么看：
–	看见 ✅ 分块 1 顺序归档、✅ 分块 2 顺序归档：说明一路绿灯，数据正安全落盘。

–	看见 ⚠️ API节点反馈详情…：会把中转站或者官方最真实的死因（如没钱了、风控了、超时了）打印出来，同时主程序会安全拦截停下。
💡 乱世通关：遇到卡死/风控的“热切换”实战无脑连招
扫书过程中，网文因为两性擦边或末日杀戮触发风控拦截（比如 Gemini 跑着跑着在分块 6 震停崩溃）是家常便饭。
